# Мой день

Личный планировщик на каждый день: пары ICEF, дедлайны Smart LMS, учёба, зал, CS2, чтение и стабильный сон.
Открывай с экрана «Домой»: **https://amirka22852.github.io/day/**

## Что он делает
- **Расписание** — личное, с hse.ru (английский 5, история поток 2, китайский, фин. инжиниринг + ML). Обновляется каждое утро в 08:20.
- **Дедлайны** — из календаря Smart LMS (только для 4-й группы), плюс контрольные из расписания и свои дедлайны.
- **План дня** строится сам: сон 00:00–07:30 (7,5 ч) каждый день → пары с дорогой → учёба по горящим дедлайнам и семинарам завтра → зал (вт, пт) → уборка (пн, 2 ч) → CS2 2,5 ч вечером → экран off → 10 страниц книги.
- **В 9:00** — уведомление со сводкой дня и фразой дня.
- Работает офлайн. Настройки и отметки хранятся на телефоне.

## Один раз настроить
1. **Settings → Pages** → Source: *Deploy from a branch* → `main` / `(root)` → Save.
2. **Settings → Secrets and variables → Actions → New repository secret**
   - `DAY_CONFIG` — `{"ical":"https://edu.hse.ru/calendar/export_execute.php?…"}`
     (ссылка — в Smart LMS: Календарь → Экспорт календаря → «Все события», «Недавние и следующие 60 дней» → «Получить URL календаря»).
     Расписание работает и без секрета: робот берёт пары группы БМПЭФ264 и оставляет только твои подгруппы.
   - `PUSH_CONFIG` — код из приложения: Настройки → «Уведомление в 9:00».
3. **Actions → Daily update → Run workflow** — проверка, что всё обновляется.
